# 코쓱톤 프로젝트

주제 **교류**를 바탕으로, 근처 사람의 상태를 알고 현실에서 대화를 시작하도록 돕는 서비스를 구체화하고 있습니다. 서비스명과 MVP 범위는 아직 확정하지 않았습니다.

## 현재 단계

자료 분석과 제품 설계 인터뷰를 진행 중입니다. `planning.md`의 **제안**은 확정된 개발 요구사항이 아닙니다. 결정이 내려지면 해당 문서에 근거와 영향을 기록하고, 구현에 필요한 화면·데이터·통신 계약·작업별 완료 조건을 구체화합니다.

팀 논의 원문은 보존합니다. 용어는 `CONTEXT.md`, 제품 범위와 남은 질문은 `docs/planning.md`에서 관리합니다. 되돌리기 어려운 구조적 결정을 내리면 `docs/adr/`에 대안과 선택 이유를 남깁니다.

개발 환경, 실행 방법, 역할 분담은 플랫폼과 팀 여건을 확인한 뒤 추가합니다.
