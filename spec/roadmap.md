# 구현 순서

[팀 계획](../docs/team-plan.md)과 [검증 ID](../docs/validation.md)를 따른다. 제품 인터뷰는 2026-09-20 사용자 최종 확인으로 완료됐다. 아래는 후속 구현 계획이다.

1. T01: 실제 Android 두 대의 설치·광고·발견·잠금 상태 기본 동작을 확인한다.
2. T02/T03: 설치 인증·프로필·관측·주변 목록을 서버와 연결한다.
3. T04: 첫 메시지·저장·실제 답장·복원을 연결한다.
4. T05: 양쪽 의도 추천과 Promptfoo 사례를 연결한다.
5. T06: 백그라운드 추천 결과 전달·시스템 알림을 연결한다. 문제 발생 시 B12 재검토 근거를 남긴다.
6. T07/T08: 회귀·실기기 시연·배포·발표 자료를 실제 증거로 정리한다.

API·화면·AI 경계를 먼저 공유하고 독립 작업은 진행하되 실제 두 사용자 통합을 끝으로 미루지 않는다. iPhone·장시간 배터리 최적화·운영 대시보드는 선행 작업이 아니다. 내부 시각·남은 인력의 실명·기기 모델은 확인 없이 배정하지 않는다.
