# 프론트와 네이티브 연결 작업

기존 React 컴포넌트·CSS는 재사용하며 제품 동작을 [화면 계약](design.md)에 맞춘다. 최신 main `16349c7`의 입력·상세·대화 목록·HTTP/SSE·오류 처리·회귀 테스트를 재사용한다. 행사별 쿠키·중단 중 송신 차단·행사 종료 처리는 새 계약으로 바꿀 대상이다. 과거 자동 답장·BLE 연결 상수는 이미 main에서 제거됐다.

1. 닉네임·자기소개·교류 의도 입력과 설치 복원 상태를 연결한다.
2. 주변 목록·상세를 실제 API로 교체하고 모든 유효 후보를 표시한다. 숫자 점수는 숨긴다.
3. 별도 요청·수락 없는 채팅과 대화 목록·재접속 이력을 구현한다.
4. Capacitor 네이티브 브리지의 시작·중지·실제 상태 조회를 연결한다. BLE와 배경 통신은 Kotlin이 담당한다.
5. 알림 상세 이동·정보 만료·권한 거부·Bluetooth OFF·통신 오류를 표시한다.
6. 행사 종료·요청함·가상 거리 보장·시연 전용 분기를 제거한다.

`sessionStorage`를 사용자 신원이나 제품 영속 저장으로 사용하지 않는다. `/api` 상대 경로가 APK에서도 기존 웹과 같은 출처라고 가정하지 않는다. [API](../docs/api-contract.md), [Android 구성](../docs/android-design.md), [배포](../docs/deployment.md)를 따른다.

동작 증거는 실제 Android 두 대에서 수집한다. 브라우저 데모와 프론트 회귀 테스트만으로 두 기기 통신을 검증한 것은 아니다. 김성빈 프론트 담당 외 네이티브 분담은 [팀 계획](../docs/team-plan.md)의 제안이다.
