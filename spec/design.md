# 화면과 상태

2026-09-20. [개발 기준](../docs/development-contract.md)의 UI 표현이다. 이전 화면 명세는 [이력](../docs/history/event-mvp/spec/design.md)에 보존한다.

| 화면 | 사용자 행동·표시 |
| --- | --- |
| 첫 실행·수정 | 닉네임, 자기소개, 지금 만나고 싶은 사람을 입력. 공개 범위를 안내하고 기존 설치 사용자는 복원 |
| 주변 목록 | 발견 ON/OFF, 실제 작동 상태, 유효한 참여자 전체를 추천 순서로 표시. 빈 목록·평가 대기·통신 오류 구분 |
| 상대 상세 | 자기소개·교류 의도·나를 위한 추천 이유, 바로 메시지 보내기. 숫자 점수는 노출하지 않으며 자동 첫마디는 필수가 아님 |
| 대화 목록 | 기존 대화와 최근 메시지. 주변 목록에서 사라져도 대화는 유지 |
| 채팅 | 별도 수락 없이 텍스트 송수신. 전송 중·저장 성공·실패/재시도 표시, 같은 메시지 중복 방지 |
| 작동 안내 | Bluetooth·권한·네트워크·OS 제한을 발견 참여 설정과 구분. 사용자가 끄면 새 발견 종료 |

요청함·수락/거절 화면·행사 선택·QR 입장·행사 종료 화면은 만들지 않는다. 주변 정보 열람 전에 입력 완료가 필요하다는 기존 정책을 유지한다. 앱 재실행 시 같은 설치의 입력·대화를 복원한다.

알림은 적합한 새 상대의 상세로 이동시킨다. 눌렀을 때 관측이 만료되거나 상대가 OFF이면 현재 상태를 표시하고 새 대화 가능 조건을 재확인한다. 이미 대화가 있으면 그 대화는 유지한다. 알림을 누른 사실을 대화 시작이나 상대 수락으로 취급하지 않는다.
