# 실제 Android 두 사용자 시연

[검증 계획](../docs/validation.md)을 실행하고 실제 성공한 단계만 발표한다. A와 B는 일반 사용자와 같은 입력·API·저장 경로를 사용한다. 별도 시연 전용 삭제나 특수 추천 결과를 넣지 않는다.

1. 두 Android에 앱을 설치하고 닉네임·자기소개·교류 의도를 입력한다.
2. 발견 참여를 켜고 실제 BLE 광고·관측으로 상대가 목록에 등장하는지 확인한다.
3. 같은 자기소개에서 의도를 바꿨을 때 추천 순서·이유가 달라지는지 근거와 함께 보여준다.
4. 홈 이동 또는 화면 잠금 뒤 새 적합 후보 발견→서버 추천→시스템 알림을 확인한다. 누르면 현재 상세를 연다.
5. 상대에게 바로 첫 메시지를 보낸다. 수락 버튼 없이 상대가 확인하고 실제 답장한다.
6. 이미 대화한 한쪽이 발견을 끄거나 멀어져도 기존 대화·이력이 이어지는지 확인한다. 대화가 없는 새 상대와의 시작 조건과 구분한다.
7. 앱을 닫았다 다시 열어 같은 설치의 소개·대화를 복원한다.

BLE 탐지 실패·알림 제한이 생기면 해당 조건을 기록한다. B12에 따라 알림 범위를 재검토할 수 있지만 모의 결과를 실제 성공으로 대체하지 않는다. 종료 뒤에도 동일 데이터 정책을 적용한다. 데이터 삭제는 이 시연의 종료 단계가 아니다.
