## 세부 내용
### 한 줄 소개

**온라인 메신저의 ‘상태 표시(Presence)’를 현실 공간으로 가져오는 근거리 상태 공유 서비스.**

### 문제

현실에서는 상대방이 지금 **말을 걸어도 되는지, 집중 중인지, 도움이 필요한지** 알기 어렵다.

온라인에서는 Slack, Discord, 메신저처럼 상태를 표시할 수 있지만, 오프라인 공간에는 이런 인터페이스가 없다.

### 해결

사용자가 자신의 상태를 간단하게 설정한다.

- 🟢 대화 가능
- 🔴 집중 중
- ☕ 같이 쉬기
- 🙋 도움 필요
- 🎮 같이 할 사람

설정한 상태는 서버에 업로드하지 않고 **BLE 등 근거리 통신으로 주변 기기에만 공유**한다.

주변 사용자는 화면 구석의 작은 상태 표시를 통해 현재 근처 사람들의 상태를 확인할 수 있다.

예:

**🟢 3명 · 🙋 1명 · 🔴 2명**

필요할 경우 상태를 눌러 간단한 메시지를 확인하거나 상대방에게 반응을 보낼 수 있다.

### 핵심 가치

기존 근거리 채팅 서비스가

**사람 발견 → 채팅 → 관계 형성**

을 목표로 한다면,

이 서비스는

**상태 표현 → 상대가 인지 → 현실에서 직접 교류**

를 목표로 한다.

즉 채팅 앱이 아니라 **현실에서 말을 걸 타이밍과 이유를 알려주는 커뮤니케이션 인터페이스**다.

### 기술적 특징

BLE Advertising/Scanning을 이용해 가까운 기기끼리 상태를 직접 공유한다.

서버, GPS, 지속적인 사용자 계정 없이도 동작하도록 설계할 수 있으며, 임시 ID와 상태 만료시간을 사용해 프라이버시를 강화할 수 있다.

**서버 없음 / 위치정보 저장 없음 / 근처에서만 보임 / 시간이 지나면 사라짐**

이라는 특성이 핵심이다.

### 대표 사용 사례

도서관에서는 `🔴 집중 중`, 해커톤에서는 `🙋 React 도움 필요`, 학교에서는 `☕ 같이 밥 먹을 사람`, 행사에서는 `🟢 대화 가능`처럼 활용할 수 있다.

### 핵심 메시지

> **온라인에는 상태 메시지가 있는데, 현실에는 없다.**

**말을 걸기 전에 서로의 상태를 알 수 있다면, 현실의 교류를 더 자연스럽게 만들 수 있다.**

    
- BM
    
    - 행사용 기능 제공(운영진, 참가자 인증 배지, 커스텀 상태, 팀 기능, 통계)
- 기술적 해자
    
    - 온디바이스AI 기반 내가 관심가질, 도움을 줄 수 있는 사람이 있을 경우 알림
        - 내 소개(관심분야) 정리하는 것도 LLM으로
    - 신호 기반 위치 정밀도 향상

### 구체적인 시나리오

- 임우현
    
    1. 일상적인 상황 : 심심해서 이 서비스에 들어가 주변 사람을 봄.
    2. 데이팅 : 서로의 정보(나이, 직업, 취미 등 사용자가 공개한 정보들)가 보이니, 마음에 드는 사람을 찾기 쉬움.
    3. 특정 장소나 행사 : 행사장에서 목적에 맞는 사람을 만나고 싶을 때
- 나강건
    
    **용례**
    
    - **운영진은 참가자들 간 교류 정도를 수치화하여 사업 보고**
    - 참가자는 궁금한 점이 있을 때 익명으로 질문
    - 공통의 관심사를 가진 사람들과 교류
    
    **유저 시나리오**
    
    - 앱 실행 → LLM 통해 프로필 생성 (키와 함께 서버에 등록) → 앱이 플로팅아이콘으로 화면에 상주하며 내 상태를 브로드캐스팅 + 주변 유저 탐색해 아이콘으로 표시
    - 원하는 상대 발견(오프라인) → [상대와 통신하여 인증](https://app.notion.com/p/3e04510cfc6380438157f01d1d1cf18a?pvs=21)(온오프라인) → 프로필 조회(온라인) → 대화 시작(오프라인)
- 우승제
    
    앱을 실행했다 가정했을 때  
    프로필(닉네임, 프로필사진 등)을 설정하고 AI를 통해 자신의 관심사, 특징 리스트화 하기  
    앱 들어가면 현재의 기분이나 상황(ex: 밥 같이 먹으실 분, 이 문제 알려주실분, 무슨무슨 일이 있어서 우울해요 ㅠㅠ 위로해주세요, 고민상담 해주실분, 롤 한판 할사람 등)을 입력할 수 있고, 이 상황이 주변에 블루투스로 연결된 사람들에게 공유됨. 공유된 상황들을 보고 관심이 있으면 채팅으로 즉시 연락가능, 이후 가까이 있으므로 만나서 오프라인으로 이야기 할 수도 있음.  
    기분이나 상황 뿐만이 아니라 주변에 자신의 관심사와 비슷한 관심사를 가지고 있는 사람이 있으면 실시간으로 추천해서 폰으로 알림이 감(ex: ~~분이 ~~분야에서 회원님과 같은 관심사를 가지고 있습니다. 이야기해보실래요? ) 이렇게 주변의 사람들과 온라인으로 교류를 할 수 있을 뿐만이 아니라 즉시 오프라인으로 교류가 확장될 수도 있음.
    
    방 기능또한 도입해서 행사 등 특정 다수에게 자신의 정보를 공유하고 싶을 때 방에 모여서 공유할 수 있음
    
    - 중요하다 생각하는 포인트
    
    1. 온라인에서 오프라인으로 이어지는 교류
    2. 무작위의 모든 사람들이 아닌 가까이 있는 사람과의 교류
