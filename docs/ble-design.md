# BLE 발견 설계 안내

2026-09-20. BLE는 이번 MVP의 핵심 발견 수단이다. Android 간, 몇 분 이상 함께 머무는 상대를 중심으로 검증한다. 채팅·추천은 인터넷 서버가 담당한다.

현재 구현 기준은 [Android 구성](android-design.md), [API v0.1](api-contract.md), [프로토콜](../spec/protocol.md)이다. API v0.1은 임시 ID를 128비트 난수의 base64url 값, 수명을 5분, 갱신 시작을 4분, 관측 기반 첫 대화 권한을 서버 수신 시점부터 10분으로 확정했으며 구현 예정이다. 광고의 서비스 UUID와 바이트 배치는 실기기 검증 뒤 별도로 고정한다. 공개 프로필·인증 자격·채팅 내용을 광고에 넣지 않는다.

이전 광고 포맷·GATT 상세 읽기·BLE 직접 메시지 분할·ACK·재시도 설계는 [초기 후보 이력](history/event-mvp/docs/ble-design.md)이다. 새 방향 채택이 그 초안의 전체 채택을 뜻하지 않는다. 실제 바이트 예산·기기 지원·광고/스캔·서버 신원 연결을 검증한 뒤 값을 고정한다.
