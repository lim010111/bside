# 이전 행사 모델의 용어

행사 방 기반 MVP에서 사용한 과거 용어입니다. BLE MVP에는 [현재 용어](../../../CONTEXT.md)를 사용합니다.

**행사 방 (Event Room)**:
하나의 행사·밋업에 참여한 사람들이 서로를 발견하고 교류하는 서비스 내 공간입니다. 같은 행사 방에 속한다는 사실이 같은 테이블이나 일정 거리 안에 있다는 뜻은 아닙니다.
_Avoid_: 근접 구역, BLE 범위, 채팅방

**참가자 (Participant)**:
자신의 정보를 등록하고 해당 행사 방에서 교류하는 사람입니다. 잠시 앱을 사용하지 않는 것과 행사 참여가 끝나는 것은 구분합니다.
_Avoid_: 현재 접속자, 계정, 대화 가능 상태

**참여 중단 (Participation Stop)**:
참가자가 자신의 의사로 행사 방의 발견 대상과 새 메시지 교환에서 빠지는 일입니다. 잠시 앱을 닫는 부재와 다르며 기존 대화가 없어지는 것을 뜻하지 않습니다.
_Avoid_: 앱 종료, 연결 끊김, 행사 종료, 대화 삭제

**참여 재개 (Participation Resume)**:
참여를 중단한 사람이 같은 참가자로 다시 발견 대상과 새 메시지 교환에 돌아오는 일입니다. 기존 대화는 이어지며 중단 중 거부된 메시지가 나중에 전달되는 것은 아닙니다.
_Avoid_: 새 참가자 등록, 새 계정, 행사 재개

**행사 종료 (Event End)**:
해당 행사 방에서 참가자 정보를 열람하고 메시지를 주고받는 이용 기간이 끝나는 시점입니다. 저장된 정보가 실제로 삭제되는 시점과는 구분합니다.
_Avoid_: 앱 종료, 일시적인 접속 중단, 데이터 삭제
