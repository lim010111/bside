# 재사용할 시각 자산

> **2026-09-19 제품 방향 전환:** 본문은 이전 행사 MVP의 명세·계획 또는 구현 자료입니다. 새 제품 방향은 BLE 기반 주변 교류이며, 이번 구현 범위와 대체 계약은 인터뷰 중입니다. 아래의 ‘현재·확정·개발 기준’ 표기를 새 방향의 승인된 요구사항으로 사용하지 않습니다. 현재 결정과 문서 전환 상태는 [BLE 근접 교류 전환](../../../product-direction.md)을 먼저 확인합니다.

기존 [web/src/index.css](../../../../web/src/index.css), [컴포넌트](../../../../web/src/components), [HTML 프로토타입](../../../../prototype/index.html)의 다크 테마·간격·카드·바텀시트·채팅 버블을 재사용한다. 기능 때문에 필요한 배치는 바꿀 수 있다. 프로토타입 동작과 카피는 현재 제품 계약의 근거가 아니다.

| 항목 | 재사용 기준 |
| --- | --- |
| 폰트 | 기존 Wanted Sans·Pretendard·시스템 폰트 fallback. 새 폰트·의존성 추가를 선행하지 않음 |
| 배경 | `--bg: #16161A`, `--surface: #202027`, `--surface-hi: #2A2A33` |
| 글자 | `--text: #F5F5F7`, `--text-dim: #8E8E9A`, `--text-faint: #5C5C68` |
| 선 | `--border: #32323C`, `--border-strong: #43434F` |
| 아이콘 | 현재 SVG 자산 우선 재사용. 인라인 18px·버튼 20px·헤더 24px는 기존 참고값 |
| 모바일 구성 | 목록에는 짧은 자기소개, 상세에는 두 원문·추천 이유와 채팅 진입. 긴 입력·오류·빈 목록도 확인 |

이전 상태색은 사용 가능한 색상 자산이며 `LOOKING_FOR`·`CAN_SHARE` 등 역할을 필수 입력으로 되살리는 이유가 아니다. `near` 밝기·닿는 거리 그룹·5분 만료선·숫자 점수 막대는 현재 제품에서는 사용하지 않는다. 상태를 보여줄 때에는 색만으로 의미를 전달하지 않고 텍스트를 함께 쓴다.

참가자 배너는 눌러 상세를 열 수 있게 하고, 채팅 전송·실패·재시도와 참여 중단 상태가 구분되게 만든다. 구체적인 변경 파일과 완료 조건은 [프론트 계획](frontend-plan.md), 공개 범위·추천·종료 동작은 [개발 기준](../../../development-contract.md)을 따른다.
