# 문서 이력

현재 기준은 [제품 결정](../product-direction.md), [개발 기준](../development-contract.md), [API](../api-contract.md)이다. 이 디렉터리의 현재·확정·필수 표현은 당시의 기록이며 현재 요구로 사용하지 않는다.

`event-mvp/`에는 이전 행사 모델의 README·CONTEXT·spec·개발/API/팀/검증/배포 계약·발표·실행 문서를 보관한다. 이력으로 옮기기 전에 존재하던 AI 후속 결정과 미커밋 수정도 보존했다. 일부 파일에는 전환 중 경고가 포함돼 있다. 링크는 접근 가능한 경로로 조정했다.

- [이전 소개](event-mvp/README.md)
- [이전 Q1~Q20과 AI 논의 원문](event-mvp/docs/planning.md)
- [이전 개발 계약](event-mvp/docs/development-contract.md)
- [이전 API](event-mvp/docs/api-contract.md)
- [이전 AI 지침](event-mvp/spec/prompts.md)
- [이전 발표](event-mvp/pitch/script.md)

요청·수락 모델은 [ADR-0003](../adr/0003-conversation-request.md)의 폐기 상태와 [ADR-0005](../adr/0005-direct-chat-uniform-data.md)에서 추적한다. 거리와 기존 대화 수명 분리는 유지한다. 공식 해커톤 자료·팀 논의 원문·커밋 리뷰·시장/기술 연구는 각 경로에 조사/이력으로 남으며 제품 계약보다 우선하지 않는다.

최신 main `16349c7`에서 추가된 [발표 덱·PDF/PPTX 안내](../../pitch/README.md)와 [행사 웹 검증 기록](../../web/VERIFICATION.md)은 기존 경로에서 이력으로 표시해 보존한다. 현재 발표안은 [BLE 발표 흐름](../../pitch/script.md)이다.
