# 새 상대와는 첫 메시지 요청을 수락한 뒤 대화한다

> **2026-09-20 폐기:** B13에서 바로 채팅으로 변경했다. 아래는 결정 이력이며 [ADR-0005](0005-direct-chat-uniform-data.md)가 현재 기준이다.

행사 소속 없이 일상 공간에서도 주변 상대를 발견하는 방향에 맞춰, 사용자는 첫 메시지를 대화 요청으로 보내고 수신자가 수락한 뒤 계속 대화하는 방식을 채택했다(B7). 수락 전에는 추가 메시지를 보내지 않는다. 기존 행사 MVP의 Q11 ‘별도 수락 없이 바로 채팅’은 새 MVP에서 이 결정으로 대체한다.

유효하게 발견된 참여자는 추천 순서로 모두 볼 수 있다(B6). 낮은 추천 평가만으로 목록에서 제거하지 않지만, 목록에서 보인다는 사실이 대화 수락을 뜻하지 않는다. 별도 수락 단계의 조작 비용을 받아들이고 수신자가 첫 메시지의 내용을 보고 대화 지속 여부를 명시적으로 선택하게 한다.

거리 이탈·발견 OFF 뒤의 요청과 대화 수명, 거절·취소·만료·재요청 정책은 [후속 결정](../product-direction.md)에서 정한다. 수락 전 메시지를 여러 개 쌓는 기존 채팅 계약을 그대로 사용하지 않는다.
