# 바로 채팅하고 시연 데이터에도 같은 정책을 적용한다

사용자는 B13에서 별도 대화 요청·수락 없이 바로 채팅하고 답장·대화 지속 여부를 사용자가 정하도록 변경했다. B14에서는 시연 데이터도 일반 데이터와 동일하게 취급하도록 결정했다. 이에 따라 요청함·수락 전 추가 메시지 제한·거절/재요청 상태와 시연 종료 후 특별 일괄 삭제 제안을 채택하지 않는다.

ADR-0003의 요청·수락 모델은 폐기한다. ADR-0004의 발견과 기존 대화 수명 분리는 유지하되 요청·수락 관련 표현은 더 이상 적용하지 않는다. 유효하게 발견한 참여자에게 첫 메시지를 보내 대화를 시작하며, 이미 시작한 대화는 거리 이탈·발견 OFF 뒤에도 열람·송수신을 유지한다. 최초 메시지를 보낼 때만 신규 대화 조건을 검사하며 별도 수락 단계는 없다.

수신자는 답장 여부를 정한다. B13에 제안했던 거절·재요청 제한·상호 차단·읽기 전용 보관 등의 상세 정책은 승인된 것으로 기록하지 않는다. 기존 연락 중단 수단과 발견 OFF를 구분한다는 취지는 유지하되, 세부 제한 기능을 이번 핵심 흐름의 선결 조건으로 추가하지 않는다.

시연 여부에 따른 별도 데이터 플래그·TTL·삭제 작업을 두지 않는다. 같은 설치에서 소개·대화를 복원한다는 B11과 거리 이탈 시 유지 정책은 모든 데이터에 동일하게 적용한다. 보관 기간이 새로 확정된 것은 아니며, 이번 MVP에서는 시간 경과만으로 제품 데이터를 자동 삭제하는 정책을 추가하지 않는다. 향후 보관·삭제 정책도 시연/일반 구분 없이 적용한다. 실제 데이터를 지금 삭제하라는 지시도 아니다.
