# 제품 방향과 검증할 가설

현재 방향은 [PRD](../spec/PRD.md)와 [B1~B14](product-direction.md)를 따른다. 이전 행사 전용 사업·주제 비교는 [이력](history/event-mvp/docs/topic-evaluation.md)에 보존한다.

검증할 가설은 사전에 방을 만들지 않아도 가까운 사람의 교류 의도를 알아보고 대화를 시작할 수 있다는 것이다. 행사는 사람이 모이는 활용 장면이며 별도 모드가 아니다. 주최자 유료 도입·일상 리텐션·시장 우위는 아직 증명되지 않은 가설이다.

실제 BLE 발견, 양쪽 의도를 고려한 추천 변화, 실제 첫 메시지·답장, 앱 밖 알림, 같은 설치 복원을 증거로 삼는다. 채팅을 실제 대면이나 사업 수요로 집계하지 않는다. 평가는 [공식 해커톤 기준](hackathon-brief.md)과 [검증 계획](validation.md)에 맞춘다. 연구 자료의 경쟁·가격·법률 주장을 현재 사실로 자동 인용하지 않는다.
