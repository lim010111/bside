# 제품 결정 안내

2026-09-20 현재 제품 결정의 원본은 [BLE 전환 기록 B1~B14](product-direction.md)이며 구현 행동은 [개발 기준](development-contract.md)을 따른다. 행사 MVP의 Q1~Q20과 당시 개발 인계는 [이력 문서](history/event-mvp/docs/planning.md)에 보존한다. 아래 AI 후속 결정은 새 방향과 충돌하지 않으므로 유지한다.

현재는 Android BLE 발견·인터넷 서버·지속 ON·발견된 전체 목록·바로 채팅·기존 대화 유지·같은 설치 복원·자동 추천 알림·시연 데이터 동일 취급을 채택했다. 별도 요청·수락 모델은 B13으로 폐기했다. 구현 코드는 아직 mock/기반 단계이며 문서 합의와 실제 동작을 구분한다.

## AI 활용·프롬프트 관리 후속 논의 (2026-09-19)

이 논의는 AI 활용 범위와 프롬프트 관리에 대한 후속 설계이며 구현 착수를 뜻하지 않는다.

- **AI-Q1 사용자 결정:** 추천에는 양쪽 교류 의도를 함께 고려한다(compromise). 의도 충돌 같은 세부 시나리오에 과도하게 집중하거나 복잡한 가중치 설계를 제품 논의의 선결 조건으로 두지 않는다. 특정 평균·최솟값 공식이나 대칭 점수를 확정한 것은 아니다. 기존 Q9와 공통 용어의 추천 점수 정의를 유지한다.
- **AI-Q2 사용자 의견:** 입력 구체화·첫마디·번역·대화 요약·운영진 요약은 핵심 기능으로 느껴지지 않는다. 이 후보들의 채택은 없으며, 핵심 교류 경험에 LLM을 더 잘 활용할 방식을 계속 검토한다.
- **AI-Q3 사용자 결정:** 프롬프트 평가 도구는 Promptfoo를 선택한다. 설치·평가 실행은 아직 하지 않았다. 원격 프롬프트 배포나 운영 추적 서비스의 추가 채택을 뜻하지 않는다. 프롬프트 지침과 평가 경계는 [AI 추천 구현 지침](../spec/prompts.md)에 기록한다.

다음 논의는 추가 AI 기능의 개수보다 사용자의 의도를 추천에 반영하는 핵심 경험을 다룬다. 아직 합의되지 않은 기능은 개발 범위나 용어집에 확정 사항으로 추가하지 않는다.
